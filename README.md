# 梦幻西游灵兽绘卷差价计算器

一个无依赖的本地网页工具，用于测算“灵兽绘卷材料 → 兑换召唤兽 → 藏宝阁出售”是否有差价。

## 使用

```bash
cd xyq-pet-arbitrage
npm start
```

浏览器打开 `http://localhost:8010/`。

## 页面入口

- `index.html`：差价计算页，按“召唤兽名字 + 技能方案”建立独立卡片，分别查看净利润与保本售价；行情参数只展示，不在这里修改。
- 技能数量直接填数字，例如 `4`，卡片和汇总里会显示为 `4技能`。
- `market.html`：区内行情页，统一维护服务器、金价、手续费，并每日记录金价和自定义物品摆摊价。
- `floors.html`：地板行情页，维护地板价格和出货时间。
- `equipment.html`：宝宝装备页，按护腕/项圈/衣服的伤害段位对比摆摊价与藏宝阁价，自动计算净差价。
- `eyes.html`：三眼九眼页，记录 105/115/125 灵石灵力价格，并按当前金价折算人民币。
- `stones.html`：灵石比价页，输入 1 级价格后自动显示 1–10 级价格，并对比藏宝阁价。
- `festival.html`：元宵珍经页，固定记录六类元宵万两价格，并单独记录炼兽珍经价格。

七个页面共用同一份本地浏览器数据，修改行情后返回计算页刷新即可参与计算。

## 输入口径

- 材料单价：万两 / 个。例如填 `10` 表示 10 万两。
- 金价：默认按“人民币 / 3000万两”填写，也就是常见的一坨币子价格；仍保留“人民币 / 万两”和“人民币 / 100万两”。例如填 `216` 并选择“元 / 3000万两”，等价于 `0.072 元 / 万两`，切换单位会自动换算。
- 藏宝阁售价：预计能成交的人民币售价。
- 野生/胚子成本：截图表格中的“加野生成本”，会直接计入总成本、净利润和保本售价。
- 手续费：默认 5%，单笔上限 1000 元；如平台规则变化可直接修改。

默认方案名包含持国巡守、谛听、多闻巡守、广目巡守、人形猫灵、涂山瞳；名字、技能数量、材料数量和价格全部可直接修改。各方案利润逐行显示，不合并成一个总价。

## 金价历史

每日填写服务器、金价和日期后点击“记录当天金价”，同一服务器同一天会覆盖旧值，并保留最近历史。记录会立即参与当前差价计算，也只保存在本地浏览器。

## 摆摊价历史

在“摆摊物品价”中自行添加物品行，手动填写物品名和单价。保存后会按同名应用到配方材料；同一物品同一天覆盖旧值，历史同样只保存在本地浏览器。

## 地板行情

内置“地板价钱以及出货时间”参考表，价格和出货时间都能直接修改，并随页面数据一起保存在本地浏览器。

当前不内置藏宝阁金价自动同步：梦幻币列表和价格趋势接口在免登录请求下分别返回空列表或 `SESSION_TIMEOUT`，公开 GitHub 爬虫也仍依赖已失效的旧 `recommend.py` 接口。

## 宝宝装备与三眼九眼

- 宝宝装备默认数据来自截图：护腕/项圈/衣服 45–65 伤害段位，摆摊价单位为“万两”，藏宝阁价单位为“元”。
- 宝宝装备净差价 = 藏宝阁售价 − `min(售价 × 手续费率, 手续费上限)` − 摆摊价 × 当前金价。
- 三眼九眼默认覆盖 105/115/125 的三眼与九眼价格，价格单位为“万两”；人民币折算 = 价格 × 当前金价。
- 以上表格都能直接修改，并随本地浏览器数据保存。

## 灵石合成

- 一梯队是“精魄灵石”，分为速度、伤害、灵力、气血、防御五类；这五行对应截图里的攻击/防御/速度/气血/灵力属性。
- 二梯队是其他宝石：黑宝石、太阳石、玛瑙、星辉石、五色。
- 每个分层表的第 1 行就是“1级价”输入框；填写后 2–10 级自动显示，不用去别的地方输入。
- 精魄灵石 1–10 级倍率：`1、2、4、8、16、32、64、132、296、724`。
- 二梯队中，玛瑙、黑宝石、太阳石按上述普通倍率；星辉石按 `3^(等级-1)`；五色石按 `1、2、5、12、29、70、169、408、985、2378`。

## 元宵珍经

- 固定提供攻击、防御、速度、躲闪、体力、法力六类元宵；只填写价格，不折算人民币。
- 炼兽珍经只有一个价格输入，并按区内行情页当前金价折算人民币。
- 元宵和炼兽珍经的价格单位均为“万两”。
