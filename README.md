# 梦幻西游工具箱

一个无依赖的本地网页工具，用于测算“灵兽绘卷材料 → 兑换召唤兽 → 藏宝阁出售”是否有差价。

## 使用

```bash
cd menghuan-xiyou-toolbox
npm start
```

浏览器打开 `http://localhost:8010/`。

## 页面入口

- `index.html`：差价计算页，顶部单个下拉框直接选择“召唤兽 · 技能数”完整方案；顶部自动扫描全部方案，只显示有净利润的方案并按利润排序。
- 技能数量在当前方案卡里选择，例如 `4技能`。
- `market.html`：区内行情页，统一维护服务器、金价、手续费，并每日记录金价和自定义物品摆摊价；页面还包含元宵珍经、打造材料价格和分解收购。
- `floors.html`：地板出货时间页，维护地板价格和出货时间。
- `equipment.html`：宝宝装备页，护腕/项圈/衣服三类卡片横向排列，按伤害段位记录摆摊价与藏宝阁价。
- `equipment-times.html`：宝宝装备出货时间页，按角色记录装备部位、伤害、属性、出货时间；梦幻时辰单独保存成字段，便于后续统计。
- `fusion-times.html`：炼妖出货时间页，按角色记录胚子组合、炼妖结果、出货时间；梦幻时辰单独保存成字段，便于后续统计。
- `pets.html`：召唤兽行情页，每只宝宝维护成长、野生成本和多个技能档（技能数、梦幻币收价、藏宝阁售价），自动按当前金价折算并比价。
- `eyes.html`：三眼九眼页，记录 105/115/125 三眼天珠和九眼天珠价格，并按当前金价折算人民币。
- `stones.html`：灵石合成页，输入 1 级价格后自动显示 1–10 级合成价格；二梯队宝石和 9 级以上精魄灵石会显示折算人民币和扣手续费后到手。
九个页面共用同一份本地浏览器数据，修改行情后返回计算页刷新即可参与计算。

顶部导航分成「价格行情」和「出货时间」两组；地板、宠装、炼妖三类出货时间页集中在最后一组，便于和价格行情页区分。

## 输入口径

- 材料单价：万两 / 个。例如填 `10` 表示 10 万两。
- 金额和数量输入支持小数点 `.`；中文输入法打出句点 `。` 时会自动转成小数点。
- 金价：默认按“人民币 / 3000万两”填写，也就是常见的一坨币子价格；仍保留“人民币 / 万两”和“人民币 / 100万两”。例如填 `216` 并选择“元 / 3000万两”，等价于 `0.072 元 / 万两`，切换单位会自动换算。
- 藏宝阁售价：预计能成交的人民币售价。
- 野生/胚子成本：截图表格中的“加野生成本”，会直接计入总成本、净利润和保本售价。
- 手续费：默认 5%，单笔上限 1000 元；如平台规则变化可直接修改。

藏宝阁出售差价会统一扣除手续费，当前覆盖绘卷召唤兽、二梯队宝石和 9 级以上精魄灵石到手价。宝宝装备、三眼九眼、元宵珍经、地板出货时间页中的地板价格是摆摊价或参考价输入，不做藏宝阁出售差价，因此不扣这笔手续费。

材料名称和单价在差价计算页统一维护，所有方案共用；单个召唤兽方案只填写自己的材料数量。默认方案名包含持国巡守、谛听、多闻巡守、广目巡守、人形猫灵、涂山瞳。

## 金价历史

每日填写服务器、金价和日期后点击“记录当天金价”，同一服务器同一天会覆盖旧值，并保留最近历史。记录会立即参与当前差价计算，也只保存在本地浏览器。

## 摆摊价历史

在“摆摊物品价”中自行添加物品行，手动填写物品名和单价。保存后会按同名应用到配方材料；同一物品同一天覆盖旧值，历史同样只保存在本地浏览器。

## 地板出货时间

内置“地板价格以及出货时间”参考表，地板价格按梦幻币 W 结算，也就是“万两”；地板名称、价格、旧数据参考和出货时间都能直接修改，并随页面数据一起保存在本地浏览器。旧数据参考只保留时间；右侧出货时间只填时间时会自动补上当天日期（例如当天是 11 月 12 日，输入 `14.28` 会保存为 `11月12日 14.28`），多个时间会自动用顿号加空格分隔。

当前不内置藏宝阁金价自动同步：梦幻币列表和价格趋势接口在免登录请求下分别返回空列表或 `SESSION_TIMEOUT`，公开 GitHub 爬虫也仍依赖已失效的旧 `recommend.py` 接口。

## 宝宝装备与三眼九眼

- 宝宝装备默认数据来自截图：护腕/项圈/衣服 45–65 伤害段位，摆摊价单位为“万两”，藏宝阁价单位为“元”。
- 宝宝装备三类卡片横向排列，只记录摆摊价和藏宝阁价，不显示成本、手续费和净差价。
- 三眼九眼默认覆盖 105/115/125 的三眼天珠与九眼天珠价格；价格默认留空，单位为“万两”；人民币折算 = 价格 × 当前金价。
- 以上表格都能直接修改，并随本地浏览器数据保存。

## 宝宝装备出货时间

- 每行记录角色、装备部位、伤害、属性和出货时间；装备部位提供护腕、项圈、衣服和其他。
- 页面不预置角色；先在顶部输入并添加角色，新增角色后会出现在所有记录的角色下拉框中。
- 出货时间沿用地板出货时间的格式：只输入时间会自动补当天日期，多个时间用顿号加空格分隔。
- 梦幻时辰按子时到亥时 30 分钟一轮自动对应；每个时辰占 2.5 分钟，多个出货时间按顺序显示并保存对应时辰。
- 记录只保存在本地浏览器，和其余页面共用同一份数据。

## 炼妖出货时间

- 页面按记录方式填写，每行包含角色、胚子组合、炼妖结果和出货时间；点击“新增炼妖记录”添加。
- 角色名复用“宝宝装备出货时间”页的角色列表；如果还没添加角色，先回到宠装出货页添加。
- 时间格式沿用地板出货时间：只输入时间会自动补当天日期，多个时间用顿号加空格分隔。
- 梦幻时辰按子时到亥时 30 分钟一轮自动对应；每个时辰占 2.5 分钟，多个出货时间按顺序显示并保存对应时辰。
- 记录只保存在本地浏览器，和其余页面共用同一份数据。

## 灵石合成

- 一梯队是“精魄灵石”，分为速度、伤害、灵力、气血、防御五类；这五行对应截图里的攻击/防御/速度/气血/灵力属性。
- 二梯队是其他宝石，顺序为：五色、月亮石、光芒石、黑宝石、太阳石、红玛瑙、舍利子、翡翠石、星辉石；不包含法防神秘石。
- 每个分层表的第 1 行就是“1级价”输入框；填写后 2–10 级自动显示，不用去别的地方输入。
- 精魄灵石 1–10 级倍率：`1、2、4、8、16、32、64、132、296、724`。
- 普通宝石 1–10 级合成数量：`1、2、4、8、16、32、64、128、256、512`。
- 星辉石 1–10 级倍率：`1、3、9、27、81、243、729、2187、6642、20898`；五色石按 `1、2、5、12、29、70、169、408、985、2378`。
- 二梯队宝石全部等级、精魄灵石 9–10 级折算人民币 = 合成价（万两）× 当前金价；扣手续费后到手 = 折算人民币 − `min(折算人民币 × 手续费率, 手续费上限)`。

## 区内行情中的分解收购

- 位于区内行情页的「分解收购」区域，包含灵饰、上古玉魄和装备吸附石三张表。
- 灵饰默认按公开攻略口径预填：60 级出 `4×1级` 星辉石，80 级出 `2×2级`，100 级出 `3×2级`，120 级出 `2×3级`，140 级出 `3×3级`。
- 星辉石等级、数量、1级星辉石价和分解符价都能直接修改，适配不同区服和规则。
- 灵饰分解符数量已内置：60/80/100/120/140 级分别为 `4/6/8/10/12` 个。
- 分解符价三张表共用，灵饰分解、上古玉魄和装备吸附石都自动使用同一价格。
- 最高收购价 = 出石数量 × 星辉石等级折算倍率 × 1级星辉石价 − 分解符数量 × 分解符价；价格低于这个值才有利润，等于它时保本。
- 默认填 `14.5万` 星辉石和 `0.1万`（1000两）分解符价，60/80/100/120/140 级最高收购价分别为 `57.6/86.4/129.7/260/390.3万两`。
- 上古玉魄按可交易玉魄固定出 `3×1级` 五色灵尘计算；需要另外填入你区的 1 级五色灵尘价。
- 上古玉魄最低成本价 = `6 × 分解符价`，只包含分解符，不包含体力。
- 上古玉魄最高收购价 = `3 × 1级五色灵尘价 − 6 × 分解符价`；它实际还消耗 `90体力`，当前未计体力成本。
- 装备分解吸附石默认覆盖 100–140 级；分解符数量内置为 `6/7/12/16/23` 个，常规/保守吸附石产出内置为 `3/3/3/4/4` 个，产出数量可改。
- 装备最高收购价 = `吸附石数量 × 吸附石价 − 分解符数量 × 分解符价`；默认吸附石 `5万`、共用分解符 `0.1万` 时，100–140 级最高收购价为 `14.4/14.3/13.8/18.4/17.7万两`。

## 区内行情中的元宵珍经

- 固定提供攻击、防御、速度、躲闪、体力、法力六类元宵；只填写价格，不折算人民币。
- 炼兽珍经只有一个价格输入，并按区内行情页当前金价折算人民币。
- 元宵和炼兽珍经的价格单位均为“万两”。

## 区内行情中的打造材料价格

- 固定四列为打造指南书、铁、灵饰指南书和元灵晶石；下方按 60/80/100/110/120/130/140/150/160 级排列。
- 打造指南书和铁覆盖 100–160 级，灵饰指南书覆盖 60/80/100/120/140/160 级，元灵晶石覆盖 60/80/100/120/140 级。
- 所有价格按“万两”填写，空白表示暂无价格；不适用的等级显示“—”。

## 数据备份

- 「区内行情」页提供“导出备份”和“导入恢复”按钮。
- 导出生成 `xyq-backup-年-月-日.json`，包含全部页面数据；建议存到网盘或 U 盘。
- 备份文件带 `schemaVersion`；导入时会先校验版本和主要字段类型，校验失败不会覆盖当前数据。
- 换电脑后打开工具箱，点“导入恢复”选择备份文件即可还原，导入会覆盖当前数据并先确认。
